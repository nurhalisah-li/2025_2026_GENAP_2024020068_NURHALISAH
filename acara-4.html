Workshop

Bootcamp Web Development Intensif

📍 Lab Komputer 1 UHM | ⏰ 08:00 - 16:00 WITA

Deskripsi Acara

Universitas Handayani Makassar kembali membuka Bootcamp Web Development Intensif. Program pelatihan satu hari ini dirancang khusus untuk membekali peserta dengan keterampilan praktis dalam membangun aplikasi web modern menggunakan teknologi terkini seperti HTML5, CSS3, dan JavaScript murni.

Instruktur Utama

  • Rizky Ramadhan, S.Kom. - Senior Frontend Developer di Perusahaan Teknologi Multinasional
  • Dewi Lestari, M.T. - Dosen Rekayasa Perangkat Lunak UHM

Detail Acara

  • Tanggal: 22 September 2026
  • Waktu: 08:00 - 16:00 WITA
  • Tempat: Laboratorium Komputer 1 (Gedung B), Kampus UHM
  • Kategori: Pelatihan Teknologi

Agenda Kegiatan

Waktu Kegiatan
08:00 - 08:30 Registrasi & Setup Lingkungan Kerja (Laptop)
08:30 - 12:00 Sesi 1: Fundamental HTML & Styling dengan Vanilla CSS
12:00 - 13:00 Istirahat & Makan Siang
13:00 - 15:30 Sesi 2: Manipulasi DOM dengan JavaScript Interaktif
15:30 - 16:00 Review Project & Pembagian Sertifikat

Informasi Pendaftaran Peserta

Pendaftaran terbuka untuk umum dan mahasiswa eksternal. Wajib membawa laptop sendiri dengan teks editor terpasang.
